# DERAIL — Project Rules

## Scope
Build ONLY the Round-1 visual/functional prototype for the hackathon.

## Core demonstration
Forward → Claim Extraction → Verification → Evidence → Verdict → Explanation

## Prototype only
Use realistic static/demo data.
The prototype must feel functional and interactive, but does NOT need real fact-checking.

## DO NOT IMPLEMENT YET
- Real web search
- RAG
- OCR
- Whisper
- PDF processing
- URL scraping
- Database
- Authentication
- Production backend
- Real-time fact checking
- Full multilingual engine

## Priority
1. Visual quality
2. User experience
3. Storytelling
4. Smooth interaction/animation
5. Clear demonstration of the concept

Keep the implementation modular so real verification capabilities can be added during the 24-hour hackathon.

Do not overbuild.
Do not turn this into a production application.
